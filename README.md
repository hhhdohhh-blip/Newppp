# Учет проектов студентов

Веб-приложение помогает преподавателю вести список учебных проектов, видеть ответственных студентов, контролировать сроки и менять статусы выполнения.

## Возможности

- Добавление проекта с названием, именем студента или команды, описанием и сроком сдачи.
- Просмотр всех проектов и общей статистики.
- Изменение статуса: запланирован, в работе, на проверке, завершён.
- Удаление проекта.
- Сохранение данных в локальную базу H2.

## Технологии

Java 17, Spring Boot, Spring MVC, Thymeleaf, Spring Data JPA, H2, Maven, JUnit 5 и GitHub Actions.

## Запуск

Нужна Java 17 или новее. Из корня проекта выполните:

```bash
./mvnw spring-boot:run
```

В Windows:

```bat
mvnw.cmd spring-boot:run
```

Откройте `http://localhost:8080`. Данные сохраняются в локальном файле базы данных в каталоге `data/`.

## Тесты и сборка

```bash
./mvnw test
./mvnw verify
```

Тесты используют отдельную H2 базу в памяти и не изменяют локальные данные приложения.

## GitHub Actions

Workflow `.github/workflows/ci.yml` запускается при push в `main` или `master`, при pull request и вручную. Он настраивает Java 17, выполняет Maven `verify` и сохраняет отчёты тестов и JAR как артефакт сборки.
